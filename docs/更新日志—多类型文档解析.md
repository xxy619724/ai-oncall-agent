# 更新日志 — 多类型文档解析

## 功能概述

知识库上传文档时，现在支持 **TXT、Markdown、PDF、Word** 四种文件类型自动解析与向量化索引。

**改前：** 只支持 `.txt` 和 `.md`，PDF 和 Word 无法上传。
**改后：** 四种类型全支持，且新增类型只需加一行代码。

---

## 架构：提取层与分片层解耦

### 为什么要解耦？

改前的问题：索引服务 `vector_index_service.py` 直接调用 `path.read_text()` 读文件，这个方法只对纯文本有效。如果要支持 PDF/Word，就得在索引服务里写 if-else：

```python
# 改前的痛点：每加一种格式就要改这里
if ext == ".pdf":
    content = extract_pdf(path)     # 写在索引服务里
elif ext == ".docx":
    content = extract_docx(path)    # 写在索引服务里
else:
    content = path.read_text()
```

这样**提取逻辑**和**索引流程**混在一起，不好维护。

### 改后的架构

```
上传文件 → [提取层] → 纯文本 → [分片层] → Document列表 → 向量存储
           ↑新服务        ↑老的
```

**提取层**（新增 `document_parser_service.py`）：根据文件扩展名路由到对应提取器，输出纯文本。
**分片层**（已有的 `document_splitter_service.py`）：接收纯文本，按策略分片。（不用改）

### 注册表模式

提取层内部维护一个字典，扩展名 → 提取函数：

```python
class DocumentParserService:
    _parsers = {
        ".txt":  _parse_text,     # 直接读 UTF-8
        ".md":   _parse_text,     # 直接读 UTF-8
        ".pdf":  _parse_pdf,      # pypdf 逐页提取
        ".docx": _parse_docx,     # python-docx 逐段提取
    }
```

想新增一种文件类型（比如 `.csv`），只需要：
1. 写一个 `_parse_csv` 方法
2. 在 `_parsers` 字典加一行 `".csv": _parse_csv`

其他代码**一行不动**。

## 每种文件类型的分片方式

| 文件类型 | 提取方式 | 分片策略 |
|---|---|---|
| `.txt` | UTF-8 直接读 | RecursiveCharacterTextSplitter(1600字符, 100重叠) |
| `.md` | UTF-8 直接读（保留 #/## 标记） | MarkdownHeaderTextSplitter(h1/h2 标题) → RecursiveCharacterTextSplitter → 合并小片段 |
| `.pdf` | pypdf 逐页提取，换行拼接 | RecursiveCharacterTextSplitter(1600字符, 100重叠) |
| `.docx` | python-docx 逐段提取，换行拼接 | RecursiveCharacterTextSplitter(1600字符, 100重叠) |

**注意：** `.md` 是唯一走 Markdown 标题分割的，其余三种类型提取出的纯文本统一走字符分割。

## 改了什么

### 改动 1：`app/services/document_parser_service.py`（新建）

提取层核心。逐文件类型看提取器实现：

**TXT / Markdown：**
```python
def _parse_text(self, file_path: str) -> str:
    return Path(file_path).read_text(encoding="utf-8")
```
就是直接读 UTF-8 文本。Markdown 也是这么读，因为 `#` 和 `##` 标记保留在文本里，分片层的 `MarkdownHeaderTextSplitter` 需要这些标记来识别标题。

**PDF：**
```python
def _parse_pdf(self, file_path: str) -> str:
    from pypdf import PdfReader
    reader = PdfReader(file_path)
    pages_text = []
    for page in reader.pages:
        text = page.extract_text()
        if text.strip():
            pages_text.append(text)
    return "\n".join(pages_text)
```
使用 `pypdf` 库，逐页调用 `extract_text()` 提取文字。每页提取出的文本不为空才加入列表，最后用换行拼接。纯文字 PDF 可以正常提取，扫描件（图片型 PDF）不支持。

**Word（.docx）：**
```python
def _parse_docx(self, file_path: str) -> str:
    from docx import Document
    doc = Document(file_path)
    paragraphs = [p.text for p in doc.paragraphs if p.text.strip()]
    return "\n".join(paragraphs)
```
使用 `python-docx` 库，遍历所有段落，提取有内容的段落的文本，用换行拼接。图片和表格中的文字不提取（RAG 场景主要关注文本内容）。

### 改动 2：`app/services/vector_index_service.py`

**改前：**
```python
# 1. 读取文件内容
content = path.read_text(encoding="utf-8")     # 只支持纯文本！
```

**改后：**
```python
# 1. 使用提取层解析文件内容（自动根据扩展名路由）
content = document_parser_service.parse(str(path))  # txt/md/pdf/docx 全支持
```

这行改动是整个功能的核心——从 "写死在代码里的 read_text" 变成了 "自动路由到正确提取器的 parse"。

**额外加的导入：**
```python
from app.services.document_parser_service import document_parser_service  # 新增
```

### 改动 3：`app/api/file.py`

**改前：**
```python
ALLOWED_EXTENSIONS = ["txt", "md"]
```

**改后：**
```python
ALLOWED_EXTENSIONS = ["txt", "md", "pdf", "docx"]
```

上传接口的扩展名白名单，不在这个列表里的文件会被拒绝。同步更新 `detail=f"不支持的文件格式，仅支持: ..."` 会自适应（因为用的 `', '.join(ALLOWED_EXTENSIONS)`）。

### 改动 4：`pyproject.toml`

```toml
"pypdf>=5.0.0",        # 新增：PDF 文本提取
"python-docx>=1.1.0",  # 新增：Word 文档提取
```

两个库都是纯 Python 实现，不需要系统级依赖（不需要装 Adobe 或 LibreOffice）。

## 如何新增一种文件类型

假设要新增 `.csv` 支持：

**第一步：写提取函数**
在 `document_parser_service.py` 的 `DocumentParserService` 类中新增：
```python
def _parse_csv(self, file_path: str) -> str:
    import csv
    rows = []
    with open(file_path, newline="", encoding="utf-8") as f:
        reader = csv.reader(f)
        for row in reader:
            rows.append(",".join(row))
    return "\n".join(rows)
```

**第二步：注册到字典**
在 `__init__` 的 `_parsers` 中加一行：
```python
".csv": self._parse_csv,
```

**第三步：加到白名单（如果想让用户上传）**
在 `file.py` 中加：
```python
ALLOWED_EXTENSIONS = ["txt", "md", "pdf", "docx", "csv"]
```

完成。不需要改 splitter、index_service、或其他任何代码。
